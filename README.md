# Data Analytics Projects

- **Excel- Coffee Sales Data Analysis.xlsx** — Excel dataset and dashboard analyzing coffee sales trends across 3 countries and 4 roast types over 4 years, using PivotTables and slicers.
- **Northwind Data Analysis.sql** — SQL analysis using the Northwind sample database, applying CTEs, joins, and aggregate functions to study revenue trends.
- **Power BI- stock market analysis Data.pbix** — Power BI dashboard analyzing 3 years of stock market data with 29 DAX measures, including RANKX and dynamic titles, to identify investment-worthy trends.
